# Legal Knowledge Twin: A RAG-Based Generative AI System for Conversational Legal Assistance

## Overview
Legal Knowledge Twin is a Generative AI-based project designed to help users find relevant information from legal documents through a conversational interface. The system uses Retrieval-Augmented Generation (RAG) to retrieve relevant content from legal PDF documents and generate context-based responses.

## Key Features
- Upload and process legal PDF documents.
- Ask questions about the uploaded legal content.
- Retrieve relevant information from documents.
- Generate context-based answers using Generative AI.
- Provide document references to help users locate relevant information.
- Support a simple, user-friendly chat interface.

## Technologies Used
- **Programming Language:** Python
- **AI Approach:** Generative AI, Retrieval-Augmented Generation (RAG)
- **Vector Database:** Qdrant
- **Backend:** Flask
- **Document Processing:** PDF text extraction

## Objective
The main objective is to make legal information easier to search and understand by enabling users to interact with legal documents through a conversational AI system.
